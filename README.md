# React + TypeScript + Vite

## Descripción

Proyecto desarrollado para practicar los fundamentos de React y TypeScript mediante el desarrollo de un carrito de compras interactivo.

La aplicación implementa componentes reutilizables, manejo de estado con hooks, renderizado dinámico de listas y estilos dinámicos utilizando React.

---

## Tecnologías utilizadas

- React
- TypeScript
- Vite
- CSS

---

## Conceptos practicados

- Componentes reutilizables
- Props
- useState
- Renderizado dinámico con map()
- Manejo de eventos
- Estilos dinámicos con CSSProperties
- Tipado con TypeScript

---

## Funcionalidades

- Incrementar productos
- Decrementar productos
- Renderizado dinámico de productos
- Cambio dinámico de estilos

---

## Instalación

Clonar repositorio:

```bash
git clone https://github.com/Cristiancamil/Curso-parctica-React.git
```

Instalar dependencias:

```
npm install
```

Ejecutar proyecto:

```
npm run dev
```
